A production-ready CSS foundation for web projects. Built on
[CUBE CSS](https://cube.fyi/) methodology and [Utopia](https://utopia.fyi/)
fluid-responsive design tokens.

## Quick start

```css
/* 1. Declare layer order (controls cascade precedence).
      It must come first: abstracts/_layers.css contains exactly this line. */
@import "cubito/abstracts/_layers.css";

/* 2. Import in any order — the layer declaration above governs precedence */
@import "cubito/abstracts/_motion.css";
@import "cubito/abstracts/_spacing.css";
@import "cubito/abstracts/_theme.css";
@import "cubito/abstracts/_typography.css";
@import "cubito/abstracts/_z-index.css";

@import "cubito/base/_reset.css";
@import "cubito/base/_button.css";
@import "cubito/base/_form.css";
/* … more base, blocks, compositions, utilities … */
```

## CSS Cascade Layers

Every file in the library is scoped to a named `@layer`. The order is declared
once, in `abstracts/_layers.css`:

```css
@layer tokens, reset, layout, blocks, utilities, theme;
```

| Layer       | Files                                                              | Priority (higher = wins) |
| ----------- | ------------------------------------------------------------------ | ------------------------ |
| `tokens`    | `abstracts/*.css`, plus the `:root` tokens each file declares      | lowest                   |
| `reset`     | `base/_reset.css`                                                  | ↑                        |
| `layout`    | `compositions/*.css`                                               | ↑                        |
| `blocks`    | `base/*.css` (except the reset), `blocks/*.css`                    | ↑                        |
| `utilities` | `utilities/*.css`                                                  | ↑                        |
| `theme`     | none — reserved for your own overrides                             | highest                  |

Component files declare their tokens in `@layer tokens` and their rules in
their own layer, so tokens never compete with component rules. Your own
un-layered CSS always beats every layer.

Utility classes intentionally have the highest precedence so a single-property
helper (e.g. `.text-center`) can always override a component default.

## Token overrides

All design tokens are defined in `@layer tokens` on `:root`. Override at any
scope — the value will propagate to every component that references the token:

```css
/* Global */
:root {
  --color-brand:  #2563eb;
  --color-accent: #f59e0b;
}

/* Per-context */
.checkout-form {
  --input-border-color: var(--color-brand);
}

/* Inline */
<button style="--button-radius: 9999px">Pill button</button>
```
